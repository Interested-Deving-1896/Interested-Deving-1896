# OpenOS-Project-OSP documentation

OpenOS-Project-OSP is the operational continuity layer of the OpenOS Project.
This documentation describes how the namespace approaches provenance,
independently verifiable copies, recovery, and portable operations across Git
hosting services.

The documentation uses **forge** for a Git hosting service, **namespace** for
the collaborative space hosted by that service, and **repository/project** for
a hosted unit of work. Platform-specific labels do not change the boundaries,
provenance, or responsibilities of the content.

license, upstream attribution, and contribution instructions.
