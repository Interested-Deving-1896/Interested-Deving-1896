# OpenOS-Project-Ecosystem-OOC documentation

OpenOS-Project-Ecosystem-OOC is the outward ecosystem layer of the OpenOS
Project. This documentation describes how the namespace supports discovery,
integration, provenance, and continuity across related open-source work and
different Git hosting services.

The documentation uses **forge** for a Git hosting service, **namespace** for
the collaborative space hosted by that service, and **repository/project** for
a hosted unit of work. Platform-specific labels do not change the boundaries,
provenance, or responsibilities of the content.

license, upstream relationship, and contribution instructions.
