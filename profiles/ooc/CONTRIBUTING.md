# Contributing to OpenOS-Project-Ecosystem-OOC

Thank you for helping OpenOS-Project-Ecosystem-OOC make related open-source
work easier to discover, understand, and connect across Git forges.

## Choose the authoritative project

OOC hosts repositories and projects with different provenance. Before making a
change, read the hosted project's README and contribution guidance and identify
its declared source. Submit code, documentation, and security fixes to that
source unless the project explicitly accepts changes here.

Use this profile repository's issue tracker for its public description,
ecosystem guidance, accessibility, or OOC-specific governance files. Because
the profile may be published automatically, maintainers may route an accepted
change into its canonical publication source.

For security concerns, follow [SECURITY.md](SECURITY.md). For general help, see
[SUPPORT.md](SUPPORT.md).

## Contribution expectations

- Keep OpenOS-Project-Ecosystem-OOC's identity and ecosystem role explicit.
- Use forge-neutral terms such as *namespace* and *repository/project* unless a
  platform-specific instruction is necessary.
- Preserve upstream attribution, licenses, provenance, and relationship
  descriptions.
- Explain integrations and compatibility without implying an endorsement or
  affiliation that has not been established.
- Keep operational documentation factual and clearly label fictional creative
  material under `characters/lore/`.
- Use descriptive links, meaningful headings, plain language, and accessible
  alternatives for non-text content.

Open a focused change that explains what changed, why it belongs in OOC, how it
was checked, and any accessibility, provenance, or ecosystem impact.

## Licensing status

This profile repository does not currently declare a project license. Do not
add or assume one without an explicit maintainer decision. Individual hosted
projects retain their own licensing. By contributing here, you confirm that you
have the right to submit the material; submission alone does not create a
license for reuse.

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).
