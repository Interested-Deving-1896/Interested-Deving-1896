# Support

## Profile and documentation help

Use this repository's issue tracker for reproducible problems with the
Interested-Deving-1896 profile, generated documentation, accessibility, or the
OSP/OOC profile templates. Include the page or file, expected result, actual
result, and relevant validation output.

For a specific software project, use that project's source repository. A
mirror may be refreshed automatically and may not accept durable changes.

## Funding and contribution tiers

Questions about active funding options, amounts, or financial terms belong on
the [OpenOS Project Open Collective](https://opencollective.com/openos-project).
README summaries are informational and the live Open Collective page is
authoritative.

## Boundaries

Community support is best-effort. This repository does not provide emergency,
paid, legal, financial, or security-response services. Report vulnerabilities
privately according to [SECURITY.md](SECURITY.md).
