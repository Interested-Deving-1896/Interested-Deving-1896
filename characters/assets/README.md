# Mirrorchain artwork

These editable SVG reference sheets are the first visual interpretation of the
Mirrorchain character canon.

| Asset | Description |
|---|---|
| [`relay-reference.svg`](relay/relay-reference.svg) | Relay shown in Source spark, Continuity prism, and Connection constellation expressions |
| [`nexus-costumes.svg`](nexus/nexus-costumes.svg) | Nexus shown in Source Weaver, Mirror Keeper, and Ecosystem Wayfinder digital cosplay costumes |

## Accessibility descriptions

### Relay reference sheet

Three views of a small charcoal-and-silver digital creature built from rounded,
visible panels. Relay has bracket-shaped listening fins, bright oval eyes, a
three-node chest light, short legs, and a luminous split tail that reconverges.
The Source version has amber light and an open notebook; OSP has cyan light and
a transparent verification prism; OOC has violet light and a small connected
constellation ribbon.

### Nexus costume sheet

Three face-neutral figures wear layered dark work coats with luminous seams and
a three-node clasp. Source Weaver uses amber accents and carries an open
notebook with branching threads. Mirror Keeper uses cyan accents and holds a
transparent comparison prism. Ecosystem Wayfinder uses violet accents and maps
a ribbon of connected stars. The poses are constructive and welcoming, with no
weapons, uniforms, or real-world insignia.
