# Security policy

## Scope

Security reports for this repository may concern workflow permissions,
credential exposure, dependency or action pinning, unsafe generated content,
or a way to compromise the profile publication chain.

Vulnerabilities in another project belong with that project's source
maintainers. Mirror repositories are not the right place for confidential
reports unless their own security policy says otherwise.

## Reporting privately

Do not disclose sensitive details in a public issue, discussion, commit, or
pull request.

Use [private vulnerability reporting](https://github.com/Interested-Deving-1896/Interested-Deving-1896/security/advisories/new)
when it is available. If that facility is unavailable, use the maintainer
contact routes listed in the [profile README](README.md) to request a private
reporting channel without including vulnerability details.

Include the affected file or workflow, impact, reproduction steps, and any
suggested mitigation. Please allow maintainers time to confirm the report and
coordinate a fix before public disclosure.

## Response expectations

This community-maintained project cannot promise a fixed response or repair
deadline. Reports will be prioritized by demonstrated impact, exploitability,
and risk to users or publication credentials.
